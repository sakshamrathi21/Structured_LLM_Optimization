\chapter{Future Steps}
We outline below several directions for future work that we plan to pursue in the coming months:
\begin{itemize}
\item \textbf{Improved Scheduler:} Experiments across multiple families indicate that a larger batch size is not always optimal—especially when the batch is heterogeneous. A potential improvement is to design a scheduler that takes into account factors such as the L2 cache size, the working set size of the current batch, the number and size of KV Cache blocks being targeted, and dynamically decides whether forming smaller, more homogeneous batches can outperform larger, mixed ones.
\item \textbf{SM-level Optimization:} In addition to the shared L2 cache, each Streaming Multiprocessor (SM) has a smaller L1 cache shared among its warps. To increase the L1 cache hit rate, it is desirable to schedule requests from the same family on nearby (or the same) SMs. The CUDA runtime scheduler typically follows a least-loaded policy—assigning kernels to the least occupied SM. However, this can lead to cache thrashing when requests from different families share the same SM. One possible approach is to assign each attention kernel an identifier derived from its family ID and preferentially schedule it on an SM already hosting requests from that family.
\item \textbf{KV Cache Offloading:} As the number of families grows, the GPU's HBM may eventually become insufficient to hold all KV Cache blocks. In such scenarios, certain blocks must be offloaded to the CPU. This necessitates the design of an efficient eviction policy, ideally guided by the degree of prefix sharing among the currently scheduled batches.
\item \textbf{Response Quality:} Thus far, our focus has been primarily on inference performance. However, another promising direction is to improve response quality for requests sharing a large common context. One approach is to fine-tune the model specifically for such shared contexts and compare its performance with that of a baseline model that receives the shared context as part of a system prompt.
\end{itemize}
