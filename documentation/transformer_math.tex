\chapter{Maths behind LLMs}
\section{Transformer FLOPs}
The motivation for this section comes from \cite{casson2023transformerflops}. Counting the number of floating-point operations (FLOPs) in Transformers is a useful way to estimate compute requirements and measure efficiency. 

\subsection{FLOPs Calculation}

Let's explain each operation and variable here:
\begin{itemize}
    \item Embed: learned token embeddings and learned positional embeddings. $d_{model}$ is the dimensionality of the residual stream.
    \item Attention: QKV: linear layer in multi-head self-attention to project input into queries, keys, and values. $n_{layers}$ is the number of layers. $d_{attn}$ is the dimensionality of the output of multi-headed attention which is equal to $d_{key} \times n_{heads}$. $d_{key}$ is the dimension of the key, query, and value projections. $n_{heads}$ is the number of attention heads in a layer. In practice, Transformers are implemented such that $d_{attn} = d_{model}$. 
    \item Attention: Mask: dot-product between query and keys. $n_{ctx}$ is the context/sequence length. 
    \item Attention: Project: linear layer to project concatenated attention heads output to $d_{model}$. 
    \item Feedforward: two linear layers in the MLP block. $d_{ff}$ is the size of the output dimensionality of the first linear layer. $d_{ff} = 4 d_{model}$ is commonly used. 
    \item De-embed: linear layer to obtain logits over vocabulary. $n_{vocab}$ is the number of tokens in the vocabulary. 
\end{itemize}


Combining all the non-embedding FLOPs terms gets us

\[C_{forward} = 2N + 2n_{layer} n_{ctx} d_{attn}\]

\subsection{Model parameters (TinyLlama-1.1B-Chat)}
\begin{align*}
L &= 22   \quad\text{(number of transformer layers)}\\
n_{\text{heads}} &= 32\\
d_{\text{ff}} &= 5632 \quad\text{(intermediate / FFN size)}\\
V &= 32000 \quad\text{(vocabulary size)}\\
n_{\text{ctx}} &= 2048 \quad\text{(context / sequence length)}
\end{align*}


\subsection{FLOPs Calculation for TinyLlama-1.1B-Chat}
\[
C_{forward} 
= 2N + 2n_{layer} n_{ctx} d_{attn} 
= 2.2 \times 10^9 + 1.84549376 \times 10^8 
= 2.3845 \times 10^9\ \text{FLOPs}.
\]

\subsection{Efficiency Calculation}
We ran inference on TinyLlama-1.1B-Chat using a single Nvidia RTX6000 Ada GPU. Based on the docs from Nvidia (\cite{adalovelacertx6000}), the theoretical peak performance for FP16 is 1457 TFLOPs.

\subsection{Efficiency Calculation}
We ran inference on TinyLlama-1.1B-Chat using a single NVIDIA RTX6000 Ada GPU. Based on the docs from NVIDIA (\cite{adalovelacertx6000}), the theoretical peak performance for FP16 is 1457 TFLOPs.

So, the time taken for a forward pass of $n_{ctx} = 2048$ tokens should be:
\[
T = \frac{C_{forward} \times n_{ctx}}{\text{Peak TFLOPs}}
\]

\[
= \frac{(2.3845 \times 10^9) \times 2048}{1.457 \times 10^{15}}
\]

\[
= \frac{4.879 \times 10^{12}}{1.457 \times 10^{15}}
\]

\[
= 3.35 \times 10^{-3}\ \text{seconds} \ (\approx 3.35\ \text{ms})
\]


During our experiments, we observed that the actual time taken for a forward pass of 100 prompts, each with a context length of 2048 tokens, was approximately 4.4s. Therefore, the time taken for a single forward pass with a context length of 2048 tokens is approximately 0.044s (or 44ms).

Thus, the efficiency can be calculated as:
\[\text{Efficiency} = \frac{\text{Theoretical Time}}{\text{Actual Time}} = \frac{3.35\ \text{ms}}{44\ \text{ms}} \approx 7.6\%\]



\subsection{Summary of the nomenclature used}
\begin{table}[h]
\centering
\begin{tabular}{|c|p{10cm}|}
\hline
\textbf{Variable} & \textbf{Meaning} \\
\hline
$d_{model}$ & Dimensionality of the residual stream (hidden size of the Transformer). \\
\hline
$L$ or $n_{layers}$ & Number of Transformer layers (blocks). \\
\hline
$n_{heads}$ & Number of attention heads in each multi-head attention layer. \\
\hline
$d_{key}$ & Dimensionality of each head’s key, query, and value vectors. \\
\hline
$d_{attn}$ & Dimensionality of the concatenated multi-head attention output. Typically $d_{attn} = d_{key} \times n_{heads} = d_{model}$. \\
\hline
$n_{ctx}$ & Context length or sequence length, i.e., number of tokens processed in one forward pass. \\
\hline
$d_{ff}$ & Size of the hidden layer in the feedforward (MLP) block. Commonly $d_{ff} = 4d_{model}$. \\
\hline
$n_{vocab}$ or $V$ & Vocabulary size: number of tokens in the tokenizer vocabulary. \\
\hline
$N$ & Total number of trainable parameters in the model. \\
\hline
$C_{forward}$ & FLOPs required for a single forward pass per token. \\
\hline
\end{tabular}
\caption{Variables used in FLOPs}
\end{table}
